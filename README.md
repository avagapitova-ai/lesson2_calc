# Семейный бюджет

Небольшой статический сайт для планирования семейного бюджета: приветственный лендинг и калькулятор доходов и расходов.

## Возможности

- **Главная страница** — краткое описание сервиса и переход к калькулятору
- **Калькулятор** — учёт доходов, обязательных и переменных расходов
- **Результат** — остаток бюджета, процент накоплений и текстовая рекомендация
- **Темы** — светлая и тёмная, переключение кнопкой в правом нижнем углу
- **Приватность** — все данные остаются в браузере, сервер не используется

## Запуск локально

Сайт состоит из HTML, CSS и JavaScript — сборка не нужна.

**Вариант 1 — через npm:**

```bash
npm install
npm start
```

Откройте в браузере адрес, который покажет терминал (обычно http://localhost:3000).

**Вариант 2 — вручную:**

Откройте файл `index.html` в браузере или поднимите любой статический сервер в корне проекта, например:

```bash
python3 -m http.server 8080
```

## Технологии

- HTML5, CSS (переменные для тем), ванильный JavaScript
- `localStorage` для сохранения выбранной темы
